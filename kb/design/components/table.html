Data table

  • source dataTable/style.js

common/dataTable — an Ant table inside a Card that can carry tabList tabs in its head. It scrolls horizontally at max-content, applies the tableHoverGradient row class when there is data, supports rowSelection, hidden and non-highlight rows, a skeleton loading pass, an error state with a retry, and the table empty state (illustration tinted primary-light-2). Pagination sits below the card and syncs to the URL.
