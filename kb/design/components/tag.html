common/tag/tag.js — default is borderless: gray200 bg, #707070 text, radius 4px, padding-inline .5em. Preset colours mix the semantic colour with white at 85% and saturate 0.24. Also supports checked (CheckableTag), closable with MdClose, hottags, animate (add-a-tag), and gradient.

Global override: style.less sets .ant-tag { font-weight: 600; padding: 0 9.5px }, which wins over the styled-component's weight 400 and .5em inline padding. Rendered tags are therefore semi-bold with 9.5px inline padding — the specimens below reflect the rendered result.
