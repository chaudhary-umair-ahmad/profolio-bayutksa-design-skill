common/filters/filters.js — the shared filter bar for listings, leads and reports. Filters are declared per tenant (tenant/*/filters), serialised into the URL query, and summarised with the FilterTag molecule. On desktop it is an inline row; below 992px the same set opens as a full-height drawer with sticky apply / reset actions.
