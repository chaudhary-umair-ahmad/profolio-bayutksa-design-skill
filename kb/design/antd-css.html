What antd actually paints

antd v5 is CSS-in-JS: a component's CSS exists only once it renders, so it is in neither the product's source nor its token scale. This is that CSS, produced by rendering each component through the product's own ConfigProvider config — read out of src/theme/index.js, not copied — and extracting the result.

Use this whenever a value looks like an antd default. The global token is not the answer: controlHeightXS is 16 and antd's Badge is 20.

Where the product overrides one of these in its own styled-components layer, the product wins — see the component register. Everything here is the floor.
