My Listings — every interactive element

The definition of done for deliverables/listings.html. One row per interactive element the product renders on /listings for Bayut KSA. Nothing is complete until every row is built-and-measured or marked N/A with a reason.

This file exists because four design "rules" in this system turned out to be one account's accidents promoted to rules — five row actions, all-disabled upgrade circles, popover radius 10, drawer head 91. A prose list of "still open" items could not catch that. A row-per-element list with a source column and a measured from column can: an unsourced row is a guess, an unmeasured row is a drawing.

Source is the file:line in profolio-reactjs that decides the behaviour — paths relative to that repo's src/.
