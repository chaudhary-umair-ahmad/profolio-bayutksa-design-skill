Iconography

The <Icon icon="MdEdit" /> atom resolves a string name against four sources in this order: components/icons.js (react-icons re-exports) → components/svg.js (local product artwork: brand marks, empty-state illustrations, BayutMatchIcon) → widgets/AmenitiesSvg → widgets/NewAmenitiesSvg. Passing styled wraps the glyph in the icon container tile. Country flags come from country-flag-icons (3×2).

Product artwork is not drawn in components: illustrations come from svg.js exports (EmptyListing, EmptyListingWidget, NetworkError, NoRecord) and from public/profolio-assets/ (188 files — per-tenant favicons and logos, images/maintenance.svg, ph-listings.svg, limit-credits.svg, REGA / ministry badges, lite/banner-faces.png). Use those files rather than redrawing.

Tag

common/tag/tag.js — default is borderless: gray200 bg, #707070 text, radius 4px, padding-inline .5em. Preset colours mix the semantic colour with white at 85% and saturate 0.24. Also supports checked (CheckableTag), closable with MdClose, hottags, animate (add-a-tag), and gradient.

Global override: style.less sets .ant-tag { font-weight: 600; padding: 0 9.5px }, which wins over the styled-component's weight 400 and .5em inline padding. Rendered tags are therefore semi-bold with 9.5px inline padding — the specimens below reflect the rendered result.

Product tag

common/product-tag — a Tag specialisation for paid products: 10px/700, white text, no border, 6px padding, line-height 1, soft-light gradient over the product colour, radius 4px, optional leading icon container.

Real defaults (product-tag/index.js): shape defaults to "round", the background comes from iconProps.color (falling back to tagBackgroundColor, then gray100), the leading icon is 1em inside a 1.4em container in white, and tagSpace is 6px — or 4px 6px when hideIconInTag is set. The name is translated through i18n.

Divider, rate, bullet & tooltip

The remaining single-purpose atoms: common/divider (pass-through to Ant), common/rate (star colour warning-color, size 13px, empty star #c6d0dc, 2px gap between stars, rate text #5a5f7d), common/listBullet (8px dot, primary-light-3 fill with a 2px #55969B ring, 8px gap) and the tooltip / popover surfaces.

Exact overlay specs (style.less): tooltip inner — min-height 40px, padding 6px 20px, 14px text in #5a5f7d on white, radius 6px, 1px #f1f2f6 border, shadow 0 8px 15px #9299b815. Collapsed-sidebar tooltips invert to black on white text; the Bayut Match tooltip drops the border for 0 0 16px rgba(0,0,0,.12). Popover inner — padding 16px, radius 0 0 6px 6px, shadow 0 5px 20px #9299b820 (heavier #9299b859 below 992px), title at weight 500 with 16px bottom margin, links #5a5f7d.
