Molecules

Every molecule here is a combination of atoms that already exists in src/components/common/* and src/components/*. Each block names its source file and the props that drive its variants, so the same composition can be rebuilt without re-reading the code.

Form field

common/textInput/textInput.js composes Label + input + ErrorMessage inside a Group with an 8px gap. Three layouts exist: stacked (default), labelIcon (a max-content auto grid with 16px gap and a 40px icon tile), and horizontal (label start, field capped at 120px). A 32px spacer column can be reserved with reserveLabelIconColumn so unlabelled rows stay aligned.

Dropdown

common/dropdown — the trigger is a full-width field-like box (10px 11px padding, radius 6px, input-border-color, placeholder text, border turns primary-color on hover / focus / open). The local Content panel is white with 0 0 2px #888, a #e3e6ef border and 6px 12px items in #888, hovering to light-gray 16% with primary text; leading icons sit 8px from the label.

Global menu (style.less): the Ant dropdown menu is min-width 200px (var --dropdown-width), radius 0 0 5px 5px, shadow 0 5px 30px #9299b820; items and anchors are 12px 24px in #5a5f7d at weight 400 with an 8px icon gap, hovering to #5f63f205. Named variants: .userDropdown 220px / Lato / 14px items / links #000 at 8px 16px, and .languageDropdown 148px / radius 4px / 1px #dedede / 13px items at 5px 16px with the active item underlined. The compact filter trigger .dropdownTrigger is 7px 12px, min-width 120px, transparent border, primary text at 600, border turning primary on hover.

Pagination

common/dataTable renders a TablePagination wrapper below the table when paginationOnBottom is set and there is more than one page. The size changer is hidden; page size defaults to pagination.pageCount or 20, and page changes are pushed into the URL query (?page=) unless noUrlPush is set.

Exact spec: items carry a 1px #f1f2f6 border on white with 4px margins (3px and radius 4px inside TablePagination) and links in #5a5f7d; the active item sits on primary-light #F7FCFC with a primary-color border and primary link. Prev / next drop their own border and run at line-height 28px; the ellipsis is #5a5f7d. The row is end-aligned, centring below 768px. Table pagination gets a 30px top margin; below 767px items shrink to 25px × 25px with line-height 22px and 5px end margins.

Thumbnail & badges

Thumbnail (components/styled.js) is a 6px-radius grid with a square, cover-fitted image. Over it sit the media counters used on listing cards, the product tag stack and the trust badges — common/bayut-match-badge, common/upgrade-icons (verified check in link-color, applied check on #28b16d) and TruCheck-style seals.

Bayut Match badge — exact spec (BayutMatchBadge.js): a fully rounded pill (9999px) in rgba(40,177,109,1) on rgba(233,247,240,1) at weight 600, line-height 1, with BayutMatchIcon in #28B16D. Two sizes — medium: 12px text, 11px icon, 5px gap, .5em / 2px padding; small: 10px text, 9px icon, 4px gap, 4px / 2px padding. It renders only when BAYUT_MATCHING_LEAD is on; a tooltip explains it on desktop, a bottom-sheet drawer on mobile.
