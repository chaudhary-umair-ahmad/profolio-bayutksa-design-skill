Card frame

common/cards — the wrapper every widget, table and section sits in. Head is at least 47px with an 18px h4 title; body padding 12px; radius 8px (10px card token) with a 1px border on desktop that drops to 0 below 992px. Card-level tabs get a 24px gutter and an ink bar in --_accent-color, which defaults to primary-color and can be overridden per card.

Global card rules (style.less): head inline padding is 24px (20px below 768px, line-height 1 below 576px), the shadow is 0 5px 20px #9299b803, the head extra slot is a centred flex row whose links are #868eae with the overflow dropdown ordered last at a 20px inline-start margin, and below 576px the head stacks into a column. A card-body spinner is absolutely centred with a 200px minimum height. The card nav (.card-nav) is 12px / 500 in #868eae, active in primary with a 1px underline 19px below.

Data table

common/dataTable — an Ant table inside a Card that can carry tabList tabs in its head. It scrolls horizontally at max-content, applies the tableHoverGradient row class when there is data, supports rowSelection, hidden and non-highlight rows, a skeleton loading pass, an error state with a retry, and the table empty state (illustration tinted primary-light-2). Pagination sits below the card and syncs to the URL.

Exact spec (dataTable/style.js + style.less):
Header cells: bg-color-light #F8F9FB, weight 400, colour light-color #9D9D9D, top and outer borders border-color-light #F1F2F6, no corner radius. Card body padding is 0 with a −1px margin, and the last row's outer cells take an 8px bottom radius.
Row hover: bg-color-light; with .tableHoverGradient the cells take linear-gradient(0deg, var(--primary-light) 0%, #fff 100%). .hidden-row is #dcdcdc; .no-highlight-row > td inherits its background.
Cells are white-space: nowrap with per-column minimums — property / location 130px (wrapping), platform actions 160px, listing actions 190px — and inline padding drops to 8px below 1366px. The bordered variant pads cells 16px 25px. A bulk-selection bar sticks to the bottom (.selectedRows, shadow 0 0 20px grey, buttons with a #20c997 border and 32px inline padding).

Rules carried through every layer
All directional spacing uses logical properties (margin-inline-*, inset-inline-*) so Arabic RTL mirrors without overrides.
Colour is never hard-coded in components: they read theme tokens, which the tenant can override at runtime via getColors().
Every data surface ships four states — loading skeleton, empty, error with retry, and loaded.
Feature availability is flag-driven (HIDE_INBOX, HIDE_REPORTS, LMS submodules, REGA/Nafath, TruBroker), so organisms must render correctly with sections absent.
Cascade order matters: theme tokens (src/theme/index.js) → styled-component rules per component → global style.less. Where the last layer restates a property it wins, which is why rendered tags are 600-weight and multi-select chips are fully rounded.
